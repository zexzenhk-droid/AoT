Aviões ideais

Instalar vozes masculinas

A app usa as vozes instaladas no sistema. Não as consigo criar — mas podes acrescentar mais, e depois aparecem na lista.

🤖 Android

1. Definições → Gestão geral (ou Sistema) → Idioma → Conversão de texto em voz
2. Motor preferido: Voz do Google → ⚙️
3. Instalar dados de voz → Português (Portugal)
4. Descarrega o pacote e escolhe uma voz masculina
5. Volta à app e recarrega — aparece no seletor

🪟 Windows

O Windows traz só a Maria (feminina) em português. Para ter masculina:

Opção A — vozes naturais (recomendado)
Definições → Hora e idioma → Voz → Adicionar voz
Escolhe Português (Portugal) ou Brasil.
As vozes Natural do Brasil incluem masculinas (Antonio, Fabio, Julio) e soam muito melhor.

Opção B — usar o Edge
O Microsoft Edge traz dezenas de vozes online, muitas masculinas. Abre a app no Edge em vez do Chrome e verás a lista maior.

Opção C — pacote de idioma completo
Definições → Idioma → Adicionar idioma → Português (Brasil) → marca Conversão de texto em voz

💡 Sotaque brasileiro num engenheiro de bordo? Nada contra — e são as únicas vozes masculinas de qualidade em português no Windows.

🔄 Como atualizar

Versão atual: v? · Última no servidor: v?

📱 Android

1. Fecha completamente a app (arrasta para cima e liberta)
2. Volta a abrir — a nova versão instala sozinha

Se não atualizar:
1. Definições → Apps → AOT Engenheiro
2. Armazenamento → Limpar dados
3. Abre a app novamente

💻 PC

1. Pressiona Ctrl + Shift + R
2. Ou fecha o browser todo e volta a abrir

Se não atualizar:
1. F12 → separador Application
2. Service Workers → Unregister
3. Ctrl + Shift + R
